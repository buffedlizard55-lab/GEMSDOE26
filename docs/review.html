Not completed, and not claimed

  • A score above 0.2477 or 0.3195: no supported new winning candidate, no external score and no upload. The existing reference is not new.
  • Independent unknown-fault validation: catalogue-thinning sensitivity is not hidden truth, and many sibling experiments reuse this area. Historical H25 all-catalogue masking leaks held-out geometry.
  • SSL causal benefit: no random-encoder control, more input weights in the SSL head, no held-out reconstruction set, only six passes. Loss reduction does not imply geological specificity.
  • Authenticated original sources: data were restored automatically from pinned owner mirrors, not a lawful organizer login. Template/value irregularities and ambiguous aliases remain open.
  • Native 1 m regional download: official metadata only; binary/full-region obtainability, vertical datum and seam processing still need verification on an unrestricted runner.
  • A live leaderboard feed or unattended submission: not implemented because Terms prohibit automatic access. Eligibility/account-holder attestations cannot be supplied by an agent.
  • Confirmed geothermal vents: no field, well, independent heat/fluid or reservoir validation.
