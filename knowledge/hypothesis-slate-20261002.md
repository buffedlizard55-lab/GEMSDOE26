# H26-next hypothesis slate and frozen XEDGE screen

**Prepared:** 2026-10-02 UTC, before any XEDGE code, new label access, or model fit.  
**Decision principle:** Maximize P(Win); own the scientific and engineering outcome. A candidate earns no submission slot because it is novel-sounding, format-valid, or locally attractive.  
**Scope:** Fault-location competition target, not a map of confirmed geothermal vents. This is a prospective screen on the already-used catalogue and spatial quadrants, not an independent confirmation set.

This slate does not alter `knowledge/preregistration.md` or rehabilitate the rejected H26-SSL-v1 result. XEDGE was listed there before that run; this document freezes its concrete transform and evaluation before its implementation. The earlier protocol and negative receipts remain immutable.

### Expected improvement and cost are not performance results

The official USGS/DOE GeoDAWN release says its magnetic/radiometric survey supports mapping and modeling; the official OSTI Gabbs Valley study describes gravity, magnetics and MT used with other geology to interpret subsurface faults/contacts. It reports a blind thermal anomaly near a two-fault intersection and a gravity high; its discussion treats hydrothermal alteration as a conditional interpretation. These sources support testing integrated geophysics under cover, **not** a unique-fault detector or a numerical leaderboard gain. See the source links below.

## Frozen H26-XEDGE v1 screen

### Inputs and order of operations

1. Verify pinned input bytes and the 100-m grid. Restore/prepare the full feature raster using the existing pipeline; all preparation and edge-feature generation must finish without importing, opening, or hashing raster-label **values**. Preserve the existing full-raster masked pretraining → masked inference → label-free anomaly order before any new fault-label access.
2. Use 0-based feature-array bands **1 (`rtp`)** and **12 (`iso_grav_anom`)**, corresponding to one-based bands 2 and 13 in the archived owner-mirror preparation receipt. This mapping is an owner-mirror description, not organizer-authenticated metadata. Use their prepared robust-normalized values; use observed masks explicitly.
3. Define valid support as the joint observed mask eroded by **48 pixels** (4 × the largest σ) using a 3×3 all-true structuring element. This excludes footprint/nodata padding from the scale-space gradients; no scores are emitted outside support.
4. For each fixed σ ∈ {3, 6, 12} pixels, apply a Gaussian filter to each normalized field and compute row/column first derivatives. At each σ, rank magnetic and gravity gradient magnitudes separately by percentile over the same valid support. Let `aσ = |g_mag · g_grav| / (||g_mag|| ||g_grav|| + 1e-6)`. This is orientation agreement of edge normals (opposite gradient signs are allowed), not evidence that the physical contrast signs match.
5. Set `cσ = sqrt(rank_magσ × rank_gravσ) × aσ`. For each field separately, calculate cross-scale line-orientation persistence `R = sqrt(mean(cos 2θ)^2 + mean(sin 2θ)^2)` from unit gradient vectors at the three scales. The fixed raw score is `S = exp(meanσ(log(cσ + 1e-6))) × sqrt(R_mag × R_grav)`. Rank `S` on support for use as one additional feature and as the edge-only ablation; set `S ≤ 0` to rank value 0 so tied no-edge pixels cannot acquire an artificial average rank of 0.5. There is no threshold, scale, weight, or score-budget search.
6. Save the exact input hashes, transform configuration, support count, feature hash and no-label-before-completion receipt before the first label read. An extraction failure, unexpected band count, nonfinite values or missing support fails closed; never silently substitute another band.

### Spatial validation and release gate

- Only after the label-free `S` and its receipt exist, read labels. Use the existing four NW/NE/SW/SE quadrant folds, the 1.5-km exclusion collar, whole-connected-component exclusion, same fixed training sample caps, same seed per fold, same 16-epoch `FaultHead` schedule and same raw 51-feature input. The XEDGE challenger adds exactly the one frozen percentile-rank feature. Also score fixed-budget **edge-only** as an ablation; it cannot replace the candidate head after results are seen.
- For each fold, use the same support halo, ridge-NMS and 1.5-pixel Poisson emission operator; keep the predeclared `60069 / 5167373` emission fraction. No mask change, count change, post-hoc padding, orientation cutoff, threshold or tuning on any fold.
- Score the identical historical H25-1 raster as an **as-emitted, catalogue-leaky local comparator**, and a matched fresh raw-feature head as the current non-historical comparator. Run 30 paired 20%-component sensitivity draws at seed offsets 60–89 (screen) and 90–119 (confirmation); report pooled DTI and each of the four spatial quadrants. These draws reuse the same known-catalogue geometry: they are not independent labels or hidden-fault truth.
- **Necessary screening gate:** the XEDGE head must exceed both H25 and raw head by at least **0.005 pooled sparse DTI** in each stage; win at least 3/4 confirmation quadrants against both; and be no worse than either by more than 0.005 pooled dense DTI. Perform the existing labels-first road/closed-claim/derived-block nuisance diagnostic and require its preregistered relative-association condition. Strict exact-grid float32 `[0,1]` TIFF validation must pass. These thresholds reuse the prior preregistered gate; no new threshold will be chosen after results.
- Passing this reused-catalogue screen is **necessary, not sufficient** for scientific proof or a claim of beating 0.2477/0.3195. The outer geography, public label catalogue and historical H25 exclusion have already been examined in this project. A pass can only justify a separately preregistered, genuinely untouched/external confirmation and account-holder review. Do not automate DrivenData access or upload. If the gate fails, preserve the TIFF as `BLOCKED_DO_NOT_SUBMIT` and spend zero weekly slots.

## Primary-source review and free-data checks

1. **USGS/DOE GeoDAWN data release:** [USGS ScienceBase item 657e1d85d34e23d3533209f7](https://www.sciencebase.gov/catalog/item/657e1d85d34e23d3533209f7), DOI [10.5066/P93LGLVQ](https://doi.org/10.5066/P93LGLVQ). The reviewed item describes airborne magnetic and radiometric surveys in western/northern Nevada and eastern California and coordinated lidar acquisition. It documents variable flight heights and survey specifications; acquisition/processing artefacts are a competing explanation. It does **not** authenticate the 19 competition-bridge channel names, gravity bands, strain fields or their physical units.
2. **Blind geothermal structural case:** [OSTI bibliographic record 1724114](https://www.osti.gov/biblio/1724114) and [full conference paper](https://www.osti.gov/servlets/purl/1724114). The official DOE record reports 480 gravity stations, 300 km of ground magnetics and 24 MT stations in Southern Gabbs Valley; the interpreted thermal anomaly is near two faults bounding an intra-basin gravity high. Magnetic-low hydrothermal alteration is worded as conditional. This is one analogue case, not a validated classifier in the competition AOI.
3. **Blind system / multiple scales:** [USGS publication 70201803](https://pubs.usgs.gov/publication/70201803). The abstract reports a blind Southern Gabbs Valley geothermal system, gravity/magnetic/MT structural interpretation, and temperature-gradient validation; the paper says the blind system had no surface hot springs, fumaroles or paleo-geothermal deposits. This demonstrates why lack of surface expression can occur in a geothermal case; it does not establish that a feature-stack edge is a fault or a vent.
4. **Official 3DEP collection:** [USGS Seamless 1-m DEM Science Data Catalog item](https://data.usgs.gov/datacatalog/data/USGS:4f34caac-f28f-4ea0-8d82-eafb2b8f9a5d), DOI [10.5066/P13LJKFS](https://doi.org/10.5066/P13LJKFS), and [National Map Products API](https://tnmaccess.nationalmap.gov/api/v1/products?bbox=-120.1%2C37.2%2C-117.8%2C40.9&datasets=Digital%20Elevation%20Model%20%28DEM%29%201%20meter&max=10). The API metadata response was retrieved for a conservative, approximate regional bounding box and returned `total=1454`; it included GeoTIFF URLs, reported byte sizes and public-domain statements. A sample subquery returned `total=7` with actual tile metadata/URLs. This confirms that official **metadata and some tile URLs** are obtainable. It does not prove every competition-footprint cell is covered or that direct bytes, datums, seams or mosaicking have been verified. Therefore DRAIN is deferred, not called ready/viable.
5. **GDR conductivity semantics:** [GDR 1390](https://gdr.openei.org/submissions/1390) describes thermal conductivity in its own resource. It cannot be used to guess the meaning of the owner-mirror `tc` feature or depth surface. Obtain the original competition feature documentation and source metadata through an authorized human account-holder path; no credentials or automated DrivenData reads are requested.
6. **Automated-access restriction:** [DrivenData Terms of Use](https://www.drivendata.org/termsofuse/). No competition-page or leaderboard refresh is part of this work. The existing 0.3195 figure remains a dated, previously retrieved snapshot, not a live feed.

## What this slate does not claim

- None of the four candidates has yet been shown to exceed the official hidden-label score.
- The XEDGE score is an edge-alignment feature, not a calibrated probability, fault map, or geothermal vent map.
- Cross-modal edges also trace lithologic contacts, intrusive bodies, survey seams, interpolator boundaries and broad basin geometry. Fault attribution needs independent geological interpretation.
- The experiment cannot repair uncertain organizer provenance by hashing an owner mirror, infer missing labels, or certify prize eligibility.
- External official 1-m metadata availability is not raw-data availability across the study area.
